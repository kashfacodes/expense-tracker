# Expense Tracker

A simple Python expense tracker that helps users manage their daily expenses.

## Features

- Add expenses
- View expenses
- Calculate total spending
- View spending by category
- Delete expenses
- Save expenses to a file
- Load saved expenses
- Handle invalid input

## Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- Loops
- File Handling
- Exception Handling

## How to Run

Run the following command:

python expense_tracker.py

## What I Learned

This project helped me practice Python programming, functions, loops, dictionaries, lists, file handling, and error handling.
